Timeline du web

Le web a à peine plus de trente ans, et il a déjà changé plusieurs fois. Remontons le temps, des premiers câbles jusqu'au web d'aujourd'hui.

Internet et le web : deux choses différentes

On confond souvent les deux. Internet est le réseau mondial de câbles, de machines et de règles de communication qui relie les ordinateurs. Le web est un service qui fonctionne sur ce réseau : des pages liées entre elles, qu'on consulte avec un navigateur.

Le courriel et de nombreux jeux en ligne utilisent aussi Internet, sans passer forcément par le web.

Web 1.0, 2.0, 3.0 : trois générations

Pour résumer l'histoire du web, on parle de trois générations : « Web 1.0 », « Web 2.0 » et « Web 3.0 ». Ce ne sont pas des versions officielles, mais des étiquettes. Elles ne se remplacent pas les unes les autres : leurs technologies existent encore toutes aujourd'hui.

  1. Web 1.0

    Le web de lecture (« read-only ») : des pages statiques en HTML, que l'on consulte sans pouvoir y répondre.

  2. Web 2.0

    Le web de participation (« read-write »). Le terme apparaît en 1999 et devient populaire en 2004. Wikis, blogs, YouTube, Facebook : les utilisateurs créent le contenu.

  3. Web 3.0

    Le web de données, ou web sémantique. Le W3C y travaille depuis 2001 : les données sont décrites pour que les machines les comprennent.

Définition retenue. Ce site suit le W3C et l'article d'Asaad Khaleel Ibrahim (2021) : le Web 3.0 est le web sémantique, ou web de données. Ses technologies existent déjà et sont utilisées sur certaines parties du web, sans avoir remplacé le Web 2.0.

À ne pas confondre avec « Web3 ». En 2014, Gavin Wood, cofondateur de la blockchain Ethereum, reprend l'expression « Web 3.0 » dans un autre sens : un web décentralisé, construit sur la blockchain. On l'écrit souvent « Web3 ». C'est une autre idée que le web sémantique présenté ici.
