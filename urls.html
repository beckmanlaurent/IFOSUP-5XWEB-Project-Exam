Les URL

Une URL, c'est l'adresse d'une page, comme une adresse postale. Apprenons à la lire de gauche à droite, morceau par morceau.

    Ce que répond le serveur

    Quand tu ouvres une adresse, ton navigateur envoie une requête au serveur. Le serveur répond toujours par un code à trois chiffres, avant même d'envoyer la page.

    Les cinq codes à connaître
    Code Ce que ça veut dire D'où vient le souci ?
    200 OK : la page est trouvée et envoyée. Aucun, tout va bien.
    404 Not Found : rien à cette adresse. Adresse erronée ou page supprimée.
    500 Internal Server Error : le serveur a eu un problème. Le serveur, pas le visiteur.
    301 Moved Permanently : la page a déménagé pour toujours. Aucun, c'est une redirection.
    302 Found : la page est ailleurs pour le moment. Aucun, c'est une redirection.

    Le premier chiffre donne la famille du code : 2 pour un succès, 3 pour une redirection, 4 pour une erreur venant de la demande, 5 pour une erreur côté serveur.

    Les redirections : 301 et 302

    Une redirection envoie automatiquement le visiteur d'une adresse vers une autre. La différence tient à la durée.

    301, déménagement définitif. L'ancienne adresse ne sert plus. Les navigateurs et les moteurs de recherche, comme Google, retiennent la nouvelle adresse.

    302, déménagement temporaire. L'ancienne adresse reste la bonne, la nouvelle ne sert que pour un temps, par exemple pendant une maintenance.
